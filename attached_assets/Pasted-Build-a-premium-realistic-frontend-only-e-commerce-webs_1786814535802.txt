Build a premium, realistic, frontend-only e-commerce website for a fictional Indian pet-care brand called **PAWLI**.

## Goal

Create a polished D2C pet-products storefront that looks like a real operating e-commerce brand and can be used as a professional web-development portfolio project.

This is **frontend only**.

Do not build:

* Backend
* Database
* Authentication
* Admin dashboard
* Real payment processing
* Real order processing
* Real customer accounts

Use realistic mock data and local state for all interactions.

---

# BRAND

**PAWLI**

Tagline:

**Better days for better companions.**

Category:

Premium pet essentials for dogs and cats.

Products include:

* Pet food accessories
* Beds
* Toys
* Grooming products
* Walking accessories
* Bowls
* Treat accessories
* Travel products

Target audience:

Urban Indian pet parents who care about quality, comfort and design.

Position the brand as:

**Modern pet care for the way you live.**

Do not make it look like a cheap pet-supply marketplace.

---

# VISUAL DIRECTION

Create a warm, premium and playful visual identity.

Use:

* Warm cream/off-white background
* Charcoal typography
* Soft terracotta or muted orange accent
* Small amounts of sage/olive as a secondary accent
* High-quality dog and cat photography
* Lifestyle photography inside modern homes
* Large editorial images
* Clean modern typography
* Generous whitespace
* Soft rounded corners
* Subtle shadows
* Smooth micro-interactions
* Minimal animations

The website should feel:

**Warm + premium + trustworthy + playful**

Avoid:

* Cartoon-heavy design
* Excessive paw-print graphics
* Neon colors
* Cheap marketplace appearance
* Excessive gradients
* Excessive rounded cards
* Excessive animations
* Generic AI-looking layouts

# FINAL DESIGN STANDARD

The final result must look like a **real premium Indian pet-care D2C brand**, not a generic AI-generated e-commerce template.

The first 5 seconds should clearly communicate:

**What is PAWLI? → Why should I trust it? → What should I buy?**

Prioritize:

**Emotion → Product → Trust → Discovery → Add to Cart → Checkout**

Keep the experience minimal and conversion-focused.

Do not add:

* Blog
* SEO sections
* Dashboard
* Complex backend
* Unnecessary pages
* Fake statistics
* Excessive animations

The final website should be polished enough to present directly as a **Kaeon Studios e-commerce portfolio project**.
